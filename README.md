# 🤖 AI Workplace Productivity Assistant

A modern AI-powered workplace productivity web application that helps professionals automate everyday office tasks using Artificial Intelligence.

This project was developed as part of the **AI Skills Acceleration Programme** to demonstrate practical AI implementation, prompt engineering, modern UI/UX design, and responsible AI usage.

---

# 📖 Project Overview

The **AI Workplace Productivity Assistant** is a responsive SaaS-style web application designed to improve workplace efficiency by using AI to automate common professional tasks.

The application enables users to:

- Generate professional emails
- Summarize meeting notes
- Create AI-powered task schedules
- Research and summarize topics
- Interact with an AI workplace assistant

The interface is designed with a clean, modern dashboard featuring a purple-themed UI, responsive layouts, and an intuitive user experience.

# 🚀 Setup Instructions

## 1. Clone the repository

```bash
git clone https://github.com/yourusername/AI-Workplace-Productivity-Assistant.git
```

---

## 2. Navigate into the project

```bash
cd AI-Workplace-Productivity-Assistant
```

---

## 3. Install dependencies

```bash
npm install
```

---

## 4. Start the development server

```bash
npm run dev
```

---

## 5. Open the application

Visit:

```
http://localhost:5173
```

---

# 🔑 Environment Variables

If using the OpenAI API, create a `.env` file in the project root.
